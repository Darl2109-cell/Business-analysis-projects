# Business Analysis Project 2 –  Sterling Trust Bank

## 📄 Overview
This project focused on streamlining the digital onboarding process for new customers.

## 🧩 Problem Statement
The client faced challenges with abandoned and rejected applications due to lack of transparency to customers and long onboarding times.

## 🧠 Approach
Interview summaries - To get interviews from different stakeholders handling different processes before mapping an AS-IS process
Analysis - Use PowerBI to generate insights on abandoned and rejection rates
Recommendation - Design a TO-BE process for building a centralized, transparent onboarding system
