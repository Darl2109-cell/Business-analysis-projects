# 📊 Digital Onboarding Performance Dashboard (Power BI)

## 🔍 Overview
This Power BI dashboard tracks dropoffs, turn-around times and error rates in real time

## 📈 Key Insights
- Percentage of customers using Mobile apps for onboarding vs Bank branches and web
- Abandoned and rejected Application count
- Rejected count by Month/ Year
- Rejection reasons by document type
- Average Verification and Resolution times.

## 🧠 Tools Used
- Power BI Desktop
- Excel for data cleaning
- DAX, Power Query
